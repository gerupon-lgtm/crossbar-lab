# CROSSBAR LAB

5桁の電話番号がクロスバー交換機でつながるまでを、図・操作・音で確かめる1ファイル教材です。

**公開ページ:** https://gerupon-lgtm.github.io/crossbar-lab/

## バージョン

- アプリ: v1.6.0
- ビルド: 2026.10.17.06
- キャッシュ識別子: `cb-lab-1.6.0-20261017-06`

## 使い方

公開ページを開き、「自動再生」または「1ステップ」を押します。音は最初の操作後に鳴ります。

「交点のしくみを実験」では、選択磁石と保持磁石がバー・つめ・接点を動かす様子を確認できます。「①選ぶ → ②つなぐ → ③選択を戻す」を試してください。発信シミュレーションでは、段ごとの交点と次段への配線を順に追えます。

`index.html`だけで動作し、外部ライブラリや音声ファイルは読み込みません。保存してブラウザで開いても使用できます。

## モデルの範囲

柔軟な選択指を使うBell型の一形式を参考にした概念モデルです。部品の間隔・動作、5桁の番号と3段の交換網などは教材向けに簡略化しています。日本のDT・RBT・BTは近似音、磁石・リレー・パルスなどの機械音は擬似音です。実機の回路図・寸法・録音を再現するものではありません。
