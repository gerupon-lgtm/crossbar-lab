# CROSSBAR LAB

5桁の電話番号がクロスバー交換機でつながるまでを、図・操作・音で確かめる1ファイル教材です。

**公開ページ:** https://cross-lab.sikumilab.com/

## バージョン

- アプリ: v1.6.3
- ビルド: 2026.10.17.10
- キャッシュ識別子: `cb-lab-1.6.3-20261017-10`

## 使い方

公開ページを開き、「自動再生」または「1ステップ」を押します。音は最初の操作後に鳴ります。

「交点のしくみを実験」では、選択磁石と保持磁石がバー・つめ・接点を動かす様子を確認できます。「①選ぶ → ②つなぐ → ③選択を戻す」を試してください。発信シミュレーションでは、交点成立後に1秒以上の確認待機を置き、選択機構を戻して保持を確認してから、交点→出口→次段の入口へ配線が約2.2秒で伸びます。到着後は1.6秒以上その状態を表示してから次へ進み、接続済み表示を残します。一時停止では線の伸長も止まり、線は再開時に途中から続けます。確認待機は再開時に待ち直します。待機は自動再生に適用し、1ステップでも配線の伸長を観察でき、描画中は次のステップへ進みません。配線を順に表示する間隔は、仕組みを見やすくするための教材上の演出です。

`index.html`だけで動作し、外部ライブラリや音声ファイルは読み込みません。保存してブラウザで開いても使用できます。

各セクションの「トップへ戻る」と画面端の「↑ トップ」で先頭へ戻れます。自動再生中に戻る場合は一時停止します。桃色の線は通話の道・段間配線、緑の点は接続中の交点、水色は保持磁石を表します。

## モデルの範囲

柔軟な選択指を使うBell型の一形式を参考にした概念モデルです。部品の間隔・動作、5桁の番号と3段の交換網などは教材向けに簡略化しています。日本のDT・RBT・BTは近似音、磁石・リレー・パルスなどの機械音は擬似音です。実機の回路図・寸法・録音を再現するものではありません。
